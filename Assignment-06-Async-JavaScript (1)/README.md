# Assignment 06 - Asynchronous JavaScript

Ten separate JavaScript solutions, one for each question.

Run an individual file with Node.js, for example:
`node Q1_Async_Coffee_Maker.js`

Q6 uses the Fake Store API and requires internet access. Use a modern Node.js version with built-in fetch, or run it in a browser console.

Random failures are intentionally simulated in several questions, so output can vary between runs.
