# Bootstrap Assignment 10

This folder contains 10 responsive Bootstrap 5 exercises.

## Contents
Each question has its own HTML file and matching CSS file:
1. Company Landing Page
2. Personal Portfolio Basics
3. Product Catalog
4. Restaurant Menu Page
5. Custom Themed Blog Homepage
6. Notifications Dashboard
7. Task Tracker with Badges
8. Pricing Plans
9. Blog Pagination
10. Travel Agency Showcase

## Run
- Extract the ZIP folder.
- Open the required `Q*_*.html` file in a modern browser.
- Internet access is required to load Bootstrap 5 CDN, Google Fonts and remote sample images.
- The Bootstrap JavaScript bundle is included only on pages that use interactive Bootstrap components (dismissible alert and carousel/navbar toggler).
