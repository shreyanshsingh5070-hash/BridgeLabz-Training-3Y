# Assignment 5 – JavaScript (ES6+)

This folder contains separate JavaScript files for all 9 questions. Browser-based questions include their own HTML files.

## Questions
1. E-Commerce Product Manager – Classes and objects
2. Student Form Validator – Forms and RegExp
3. Library Management System – Classes and objects
4. Custom Form Builder – Forms and classes
5. Movie Ticket Booking – Objects and RegExp
6. Employee Management System – Classes and object methods
7. Login Form Validation – RegExp
8. Dynamic Object Updater – DOM and objects
9. Shopping Cart Total – Classes and coupon RegExp

## Run console-based programs
Open a terminal in this folder and run, for example:
`node Q1_Ecommerce_Product_Manager.js`

Console-based files: Q1, Q3, Q6, Q9.

## Run browser-based programs
Open the matching HTML file in a browser:
- `Q2_Student_Form_Validator.html`
- `Q4_Custom_Form_Builder.html`
- `Q5_Movie_Ticket_Booking.html`
- `Q7_Login_Form_Validation.html`
- `Q8_Dynamic_Object_Updater.html`

Each HTML file loads its matching JavaScript file.

Only core JavaScript (ES6+) is used. No frameworks or external libraries are required.
