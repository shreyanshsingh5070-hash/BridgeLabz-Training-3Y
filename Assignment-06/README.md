# Assignment 6 – JavaScript (ES6+)

This folder contains separate JavaScript files for all 9 questions.

## Questions
1. Callback greeting
2. Applying operations using callback functions
3. Arrow function `this` and normal function `this`
4. Constructor functions and prototype method sharing
5. Person–Student prototype inheritance
6. Person–Faculty–Professor prototype chain
7. Closure using a multiplier function
8. Custom Array `myMap()` method
9. Person–Student inheritance using ES6 classes, `extends`, and `super()`

## Run the programs
Open a terminal in this folder and run a file with Node.js, for example:

`node Q1_Callback_Greeting.js`

All questions in this assignment can be tested using Node.js. Only core JavaScript is used; no frameworks or external libraries are required.
