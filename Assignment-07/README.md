# Assignment-07: JavaScript DOM Practice

This folder contains nine separate JavaScript solutions. Each question has:
- One `.js` file containing the JavaScript logic.
- One matching `.html` file to run and test the solution in a browser.

## How to run
1. Extract the ZIP file.
2. Open the matching HTML file for the question in a web browser.
3. Interact with the page and check the browser console if needed.

All solutions use core JavaScript (ES6+) with HTML and CSS; no frameworks are used.
