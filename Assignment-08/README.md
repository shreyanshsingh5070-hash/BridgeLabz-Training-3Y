# Assignment 08 - JavaScript OOP and Array Methods

This folder contains nine separate JavaScript files, one for each question.

## Run
Use Node.js from this folder, for example:
`node Q1_Student_Result_Processing.js`

You can also paste an individual file into the browser developer console.
No external libraries or frameworks are required.

## Assumptions used
- Q1 sample grade boundaries: A >= 80, B >= 60, C >= 40, otherwise F.
- Q5 sample fare formula: ₹40 base fare + ₹12 per kilometre.
- Q6 low stock means fewer than 10 units.
