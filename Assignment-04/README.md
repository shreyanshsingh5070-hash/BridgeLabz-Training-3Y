## How to run
- Open a terminal in this folder.
- Run a file using: `node Q1_Personalized_Login_Greeting.js`
- Replace the sample values inside each file to test other inputs.
- Alternatively, paste a file's code into the browser developer console.

Only core JavaScript is used; no frameworks or libraries.
